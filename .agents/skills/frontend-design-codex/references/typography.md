# Typography

Use this reference when typography is a meaningful part of the design task.

## Respect existing fonts

If the repository defines brand or application fonts, use them unless the user explicitly requests a change.

Do not replace a working type system merely to create novelty.

## Hierarchy

Define clear roles such as:

- display;
- page title;
- section title;
- body;
- secondary body;
- label;
- caption;
- metadata.

Use size, weight, line height, spacing, and color intentionally rather than changing every property at once.

## Readability

Maintain suitable line height and line length for long text.

Avoid extremely light weights on low-contrast surfaces.

## Multilingual interfaces

When Latin and Arabic or other scripts coexist, verify that:

- each font supports required glyphs;
- visual weight is balanced;
- line heights work for both scripts;
- fallback fonts do not create visible jumps;
- punctuation and numerals render correctly.

## Density

Dense tools may require compact typography; media or editorial interfaces may use larger display type.

Match typography to content density and user tasks.

## New projects

For greenfield work, avoid defaulting automatically to generic fonts solely because they are common.

Select typefaces that fit product tone, language support, performance, and licensing constraints.
