# Visual Design Guidance

Use this reference for redesigns, new interfaces, and substantial visual refinement.

## Establish a direction

Before coding, decide the visual concept based on product purpose and audience.

Possible directions include refined minimalism, cinematic, luxury, editorial, futuristic, industrial, utilitarian, playful, organic, brutalist, geometric, immersive, dense professional tooling, or another clearly justified aesthetic.

Do not choose a style merely because it is currently fashionable.

## Product hierarchy

Identify:

- primary task;
- primary action;
- most important content;
- secondary information;
- low-priority metadata.

The visual hierarchy should reflect this order.

## Differentiation

A strong interface should have at least one recognizable characteristic such as:

- distinctive typography;
- memorable navigation;
- cinematic artwork treatment;
- unusual but usable composition;
- deliberate density;
- characteristic surface hierarchy;
- strong motion language.

Do not add novelty that harms comprehension.

## Spatial composition

Avoid defaulting to centered containers with equal cards.

Use layout intentionally through:

- asymmetry;
- negative space;
- controlled density;
- layered media;
- full-bleed artwork;
- editorial grids;
- sticky regions;
- adaptive columns;
- focal hierarchy.

## Color and surfaces

Prefer semantic roles over arbitrary literals:

- background;
- surface;
- elevated surface;
- overlay;
- primary text;
- secondary text;
- muted text;
- accent;
- border/divider;
- success/warning/error.

Preserve existing theme tokens when available.

Visual effects such as blur, glow, gradients, translucency, noise, and shadows should reinforce the concept, not act as decoration by default.

## Avoid generic AI aesthetics

Avoid:

- purple gradient startup styling without brand justification;
- glass cards everywhere;
- huge empty hero areas;
- repeated identical rounded cards;
- decorative gradients that communicate nothing;
- arbitrary glow around every interactive element;
- cookie-cutter SaaS composition;
- excessive pill controls.

## Refinement pass

After implementation inspect:

- alignment;
- spacing rhythm;
- optical icon balance;
- surface hierarchy;
- border consistency;
- text wrapping;
- visual density;
- empty areas;
- focal priority;
- light/dark consistency;
- artwork cropping.

A polished interface often depends more on this pass than on adding more features.
