### 2. Hardware decoding and software fallback

- **VERIFIED:** First `_createEngine()` defaults to `softwareDecoding=false` and passes `hardwareAcceleration: !softwareDecoding`; Android therefore explicitly requests MediaCodec. The plugin's null-hwdec default (`auto-safe`, with an emulator check) is bypassed by NOVA's explicit value; the decoder-list `h264` check proves only decoder availability in the library, not hardware support for the actual stream. `video_player_page.dart:240`, `:384–405`; engine `:110–118`; `MVA:136–169`.
- **VERIFIED:** Watchdog runs with the five-second progress timer. Before known duration, buffering more than 45 seconds after open sets `_stuck` (no software retry in that branch). After duration becomes known (`ready`), buffering at **position zero** for more than 45 seconds after `_readyAt` recreates an accelerated engine as software; an already-software engine sets `_stuck`. It does not detect steady-state frame stutter at a nonzero position. `video_player_page.dart:225–230`, `:427–459`; engine `:164`.
- **VERIFIED:** Separate error fallback requires failed + accelerated engine + page `_softwareDecodeRetryUsed=false` + an error containing `codec`, `decoder`, `decoding` or `hwdec`. A microtask retires the old engine, captures position when not awaiting resume, then opens software. The page latch bounds this error path; the watchdog does not consume that latch, but tests the current engine's acceleration boolean. Manual retry clears the page latch and creates the default accelerated engine. `video_player_page.dart:462–471`, `:495–513`, `:547–559`, `:1869–1878`.

### 4. Torrent-to-player data path

- **VERIFIED:** The active torrent downloads into a documents/torrents directory; `prepare` returns a **local HTTP URL** `http://127.0.0.1:<ephemeral-port>/stream`, not a pipe or direct file URL. `StreamServer` serves the selected on-disk file with GET/HEAD and byte ranges; `availableBytes` calls native `readableBytes` before reading. `torrent_service.dart:398–417`, `:437–481`, `:505–514`; `stream_server.dart:62–79`, `:118–164`, `:238–311`.

OS page cache may serve reads, so the code does not prove physical-disk read volume or duplicate physical writes. **UNKNOWN:** Exact CPU/I/O cost, mpv cache-file growth, buffering frequency or which layer caused the user's stutter.
