# NOVA 1.0.5 — build 68

## العربية

- **المشاهدة الجماعية:** إنشاء غرفة أو الانضمام برمز دعوة، مع دردشة ومزامنة تشغيل وتحكم للمضيف وخيار التحكم الجماعي. يتطلب حساب NOVA وملفًا شخصيًا نشطًا؛ لا تتوفر الميزة في وضع الأطفال أو للضيوف.
- **تخصيص البطاقات:** التحكم بحجم الملصقات والزوايا والشكل والعناوين والشعار من إعدادات العرض.
- **واجهة التصفح والمشغل:** تحديث عرض الصفوف والواجهة الرئيسية والتفاصيل وأدوات المشغل، مع تحسينات لاتجاه النص والتخطيطات العربية والإنجليزية.
- **روابط الدعوة:** دعم فتح دعوات المشاهدة الجماعية داخل التطبيق على Android.

الإصدار `1.0.5`، البناء `68`. الحد الأدنى المدعوم يبقى البناء `60`. يجب إرفاق ملف APK الموقع المطابق باسم `app-release.apk` بإصدار GitHub `v1.0.5` قبل استخدام التنزيل من داخل التطبيق. يحتاج تشغيل المشاهدة الجماعية بين أجهزة حقيقية ومظهر الواجهات إلى تحقق على الأجهزة.

## English

- **Watch Party:** Create or join a room with an invite code, chat, synchronized playback, host controls and optional group control. A signed-in NOVA account and active profile are required; Kids and guests are excluded.
- **Poster customization:** Adjust card scale, corners, shape, labels and logo from Display settings.
- **Browse and player UI:** Refined Home rails, details and player tools, including Arabic and English layout improvements.
- **Invite links:** Android opens Watch Party invitations in the app.

Version `1.0.5`, build `68`; minimum supported build remains `60`. Attach the matching signed APK as `app-release.apk` to GitHub release `v1.0.5` before using in-app download. Multi-device Watch Party playback and device visuals still require physical-device acceptance.
