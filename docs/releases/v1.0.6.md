# NOVA 1.0.6 — build 69

## العربية

- يملك iOS الآن بيانات إصدار مستقلة عن Android؛ لم تعد أرقام بناء Android تؤثر على تحديثات iPhone.
- عند توفر إصدار iOS أحدث ورابط توزيع صالح، يظهر تنبيه اختياري عند بدء التطبيق مرة واحدة لكل إصدار، كما يمكن التحقق يدويًا من صفحة «حول».
- يفتح زر iOS صفحة الإصدار الخارجية. توزيع `Nova-release-unsigned.ipa` عبر iLoader يتطلب تنزيل الملف وتوقيعه وتثبيته من iLoader؛ لا يثبت NOVA الملف بنفسه.
- هذه النسخة هي التثبيت الأول المطلوب لإضافة منطق التحديث إلى iPhone. تبقى بيانات iOS في `version.json` غير مفعّلة حتى يصبح إصدار IPA الجديد متاحًا فعلًا.

الإصدار `1.0.6`، البناء `69`. ملف Android المطابق هو `app-release.apk` ويجب رفعه إلى إصدار GitHub `v1.0.6` قبل الاعتماد على رابط التنزيل من داخل التطبيق.

## English

- iOS update metadata is separate from Android build numbers.
- When a newer iOS build and a valid distribution page are available, NOVA offers a dismissible launch notice once per release and a manual check in About.
- The iOS action opens an external release page. With iLoader, the unsigned IPA still has to be downloaded, signed and installed through iLoader.
- Install this build once through the existing iLoader flow to add the new update-check logic. iOS manifest fields remain inactive until the new IPA release is actually available.

Version `1.0.6`, build `69`. Attach the matching Android `app-release.apk` to GitHub release `v1.0.6` before using in-app download.
