# NOVA 1.0.9 — build 72

## العربية

- أصلحنا صور الهيرو على الجوال لتملأ مساحته بالطول والعرض، مع نقاط متقاربة في الوسط تميّز الشريحة الحالية بطول إضافي بسيط.
- أضفنا عناصر UIKit النظامية على iPhone وiPad للتأكيدات والقوائم ومفاتيح التبديل في الواجهات المناسبة، ليتبع مظهرها Liquid Glass على iOS 26.
- تبقى النماذج والمحتوى والمشغّل ضمن واجهة NOVA، مع عناصر Flutter الاحتياطية عندما لا يتوفر الجسر الأصلي.

الإصدار `1.0.9` والبناء `72`. يتطلب تحديث Android إرفاق ملف `app-release.apk` الموقّع بنفس مفتاح النسخة المثبتة بإصدار GitHub `v1.0.9`. ينتج Codemagic ملف `Nova-release-unsigned.ipa` بهذا الرقم لبناء iOS، ثم يُوقَّع ويُثبَّت عبر iLoader. لا تُفعّل بيانات تحديث iOS داخل التطبيق حتى يتوفر رابط تثبيت مباشر صالح على الهاتف.

## English

- Refined the phone hero artwork to fill its full portrait area, with closely spaced centered pagination dots and a slightly longer active dot.
- Added native UIKit confirmations, choice menus and switches on appropriate iPhone and iPad surfaces. iOS 26 supplies the system Liquid Glass appearance.
- Forms, media content and playback remain in NOVA's existing UI, with Flutter fallbacks when the native bridge is unavailable.

Version `1.0.9`, build `72`. Attach an `app-release.apk` signed with the installed app's key to GitHub release `v1.0.9` for Android updates. Codemagic prepares `Nova-release-unsigned.ipa` with the same version for signing and installation through iLoader. iOS update metadata remains inactive until a usable on-device installation URL exists.
