# NOVA 1.0.8 — build 71

## العربية

- أصبحت الواجهة الرئيسية وواجهتا الأنمي والأطفال تعرض العمل المميز بصورة ممتدة تشغل 78% من ارتفاع الشاشة، مع العنوان والإجراءات فوق الصورة.
- حلت نقاط اختيار الشرائح محل الصور المصغرة أسفل الهيرو. النقطة الحالية أطول قليلًا، ويمكن الضغط على أي نقطة للتبديل.
- يحتفظ الهيرو في صفحة التفاصيل بتخطيطه المعتاد.

الإصدار `1.0.8`، البناء `71`. يطابق `version.json` هذا الإصدار؛ يجب إرفاق `app-release.apk` بإصدار GitHub `v1.0.8` حتى يعمل رابط تحديث Android. يتحقق Codemagic من رقم الإصدار والبناء داخل تطبيق iOS وملف `Nova-release-unsigned.ipa`. يتطلب ملف IPA التوقيع والتثبيت عبر iLoader، وتظل بيانات تحديث iOS غير مفعّلة إلى أن يتوفر رابط توزيع صالح على الهاتف.

## English

- Home, Anime and Kids now show immersive featured artwork at 78% of screen height, with title and actions over the image.
- Centered slide dots replace the thumbnail strip. The selected dot is slightly longer and each dot selects its slide.
- Detail pages retain their existing hero layout.

Version `1.0.8`, build `71`. Attach the matching `app-release.apk` to GitHub release `v1.0.8` for the Android in-app update URL. Codemagic verifies the version and build inside the iOS app and packaged `Nova-release-unsigned.ipa`. The IPA still needs signing and installation through iLoader; iOS update metadata stays inactive until a usable phone-side distribution URL exists.
